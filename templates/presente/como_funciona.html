  • Como funciona
    • {% endblock %} {% block app_content %}

    Cada presença registrada pelo QR Code gera pontos. Os pontos fazem o aluno subir de nível, aparecer no ranking e trocar por brindes. Trilhas, conquistas e bônus de diversidade dão pontos extras.

    Pontos por presença

    Cada atividade define quantos pontos vale. O aluno ganha ao registrar presença, uma vez por atividade. Se a presença for removida, os pontos são estornados.

    Trilhas

    Uma trilha agrupa atividades sobre um tema. Quem completa o número mínimo de atividades ganha o bônus da trilha.

    • Trilha de um evento: o aluno escolhe participar na página Trilhas.
    • Trilha sem evento: vale automaticamente para todos.

    Ranking e loja

    O ranking mostra o saldo de pontos de cada evento. Na loja, os pontos viram brindes; a troca desconta os pontos do saldo e, portanto, também do ranking daquele evento.

    Para quem organiza: criando uma atividade gamificada
    1. Preencha as informações para o participante: título, local, horário e descrição. Elas aparecem para o aluno quando ele toca na atividade dentro da trilha.
    2. Defina os pontos pela presença. Uma boa referência: 10 pts para uma palestra, 20 a 30 pts para uma oficina mais longa. Use 0 se a atividade não deve dar pontos.
    3. Escolha uma trilha (opcional). Só aparecem trilhas sem evento ou do evento selecionado. As trilhas são criadas pela administração, no painel admin.
    4. Escolha uma área (opcional) para a atividade contar no bônus de diversidade.
    5. Confira a caixa "O participante vai ver": ela resume exatamente o que o aluno ganha.
